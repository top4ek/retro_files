Durell Software — британская компания из Тонтона, основанная Робертом Уайтом и выпускавшая игры для домашних компьютеров в 1980-х годах.
Среди её игр — Harrier Attack, Saboteur и [Scuba Dive](../../vector06c/scubadive_dx/): оригинальную версию Scuba Dive для ZX Spectrum создал Майк Ричардсон.
