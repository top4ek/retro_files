Чтение с ленты картинок в формате ZX Spectrum.

Программа ZX Read является программой которая  связывает  три  различных

формата записи:

    1. ZX Spectrum ( SCREEN )  <- магнитофон

    2. Вектор-06ц ( MON )      <- магнитофон

    3. Вектор-06ц ( [МикроДОС 28](../microdos/yanus) )  <- дисковод

   В целом редактор имеет следующие функции и режимы :

    1. Выход в операционную систему;

    2. Чтение файла с диска;

    3. Запись файла на диск;

    4. Чтение файла с ленты в формате ZX SPECTRUM;

    5. Запись файла на ленту в формате ZX SPECTRUM;

    6. Чтение файла с ленты в формате ВЕКТОР-06ц (MON);

    7. Запись файла на ленту в формате ВЕКТОР-06ц (MON);

    8. Инвертирование экрана;

    9. Очистка экрана.
