Данная библиотека времени исполнения предназначена для профессионального написания прикладных программ для компьютера ВЕКТОР-06ц.

В данную версию библиотеки входит:

- набор графических утилит для L/R

- драйвер и функции текстового режима для L/R ( 32 символа в строке, 21 строка, знакоместо 8 на 12 пикселов )

- набор графических утилит для H/R

- драйвер и функции текстового режима для H/R ( 64 символа в строке, 16 строк, знакоместо 8 на 16 пикселов )

- драйвер видеоконтроллера с системой программных прерываний

- драйвер клавиатуры с системой программных прерываний

- драйвер таймера i8253 для исполнения 3-х канальной музыки

- драйвер устройства УСПИД-джойстик

- библиотека арифметических функций

Скорость работы всех компонентов библиотеки значительно повышена в сравнении с печально известным пакетом ДРАЙВЕРЫ УСТРОЙСТВ ( например скорость вывода на экран прямоугольника увеличена в 4 раза ).
Другим преимуществом данной библиотеки является разделяемость программных модулей при компоновке из единого библиотечного файла PPCLIB.REL, в котором поставляется библиотека.
ВСЕ перечисленные ниже процедуры работы с экраном учитывают разрешение и запрещение видеоплоскостей ОЗУ (аналогично оператору SCREEN 2,X в БЕЙСИКЕ v.2.5), что позволяет создавать специальные видеоэффекты, или использовать часть видеопамяти для нужд Вашей программы.
ГАРАHТИРУЕТСЯ, что при работе с видеопамятью ТОЛЬКО средствами библиотеки, запрещенная плоскость ( или плоскости ) останется неизменной.
