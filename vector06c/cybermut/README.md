По далекой планете летит обыкновенный кибермутант и расстреливает пакманов, которые, не имея на этой самой планете естественных врагов, заполонили собой всё обитаемое пространство.
Кибермутант может сам мутировать в пакмана и атаковать сверху, демонстрируя себя в непривычном ракурсе.
