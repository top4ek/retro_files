# ATAS - альтернатива ассемблеру

## Введение

ATAS разработан как удобная альтернатива ассемблеру.
Программа, написанная на атасе, весьма напоминает программу на языке высокого уровня, но оперирует регистрами процессора также как и переменными.
В атасе вместо мнемоник типа `ADD`, `SUB` и т.п. используются знаки `+`, `-` и т.д.
Данное описание атаса рассчитано на программиста, вполне освоившего ассемблер.

## Трансляция

Транслятор атаса преобразует исходный текст в текст на ассемблере, что позволяет использовать уже наработанное программное обеспечение для ассемблера и на ассемблере.

Пример:

```
A>ATAS
FILE - ? PROG.ATS     - входной файл
REM. (Y/..) Y         - комментарии и исходные выражения
                        в выходном файле
```

Выходной файл имеет имя входного и расширение `ASM`.

## Выражения

Выражение - цепочка литер, ограниченная разделителями.
Разделитель - пробел или любой знак с кодом меньше `20H`.

## Регистры

Под регистры зарезервированы имена: `A`, `B`, `C`, `D`, `E`, `H`, `L`, `M`, `BC`, `DE`, `HL`, `SP`, `PC`.

## Константы и переменные

Константы и переменные любые допустимые в ассемблере.
Сложные константы и переменные заключаются в круглые скобки.
Вложение круглых скобок недопустимо.

Пример:

```
A=(X+10H)     ->  LDA  X+10H
DE=^(Y+X)     ->  LXI  D,Y+X
```

Операции над непосредственными данными обозначаются знаком `^` (разадресация).

Пример:

```
A=B-^X        ->  MOV  A,B
                  SUI  X

DE=^X         ->  LXI  D,X
```

Операнды, начинающиеся с цифры, автоматически воспринимаются как непосредственные данные.

Пример:

```
BC=HL+300H    ->  LXI  D,300H
                  DAD  D
                  MOV  C,L
                  MOV  B,H
```

Можно прямо указать адрес операнда, если заключить его в круглые скобки.

Пример:

```
Y=X+(6045)    ->  LDA  X
                  LXI  H,6045
                  ADD  M
```

## Мнемоники

Мнемоники ассемблера, используемые в атасе: `DAA`, `NOP`, `RET`, `RC`, `RNC`, `RZ`, `RNZ`, `RM`, `RP`, `RPE`, `RPO`, `HLT`, `EI`, `DI`, `END`, `JMP`, `JC`, `JNC`, `JZ`, `JM`, `JP`, `JPE`, `JPO`, `CALL`, `CC`, `CNC`, `CZ`, `CNZ`, `CM`, `CP`, `CPE`, `CPO`, `RST`, `IN`, `OUT`, `ORG`, `DS`, `DW`, `DB`, `EQU`.

Пример: `ORG 100H` , `JMP M1` , `X: EQU 60+P` , `RET` .

## Пересылки

| Вид | Примеры |
| --- | --- |
| регистр-регистр | `A=B`  `E=C`  `D=E`  `H=A`  `HL=DE`  `DE=BC` и т.д. |
| константа-регистр | `A=^CONST`  `E=800H`  `BC=5`  `HL=^X` |
| переменная-регистр | `C=X`  `B=Y`  `DE=(80)` (переменная по адресу 80) |
| регистр-переменная | `X=C`  `Y=B`  `80=DE` |
| переменная-переменная | `Y=X`  `80=(81)`  `.YW=XW` (двухбайтовая пересылка) |
| константа-переменная | `X=^CONST`  `.YW=2480H` |

## Операции

| ATAS | ASM | Описание |
| --- | --- | --- |
| `+` | `ADD` | сложение |
| `++` | `ADC` | сложение с учётом переноса\* |
| `-` | `SUB` | вычитание |
| `--` | `SBB` | вычитание с учётом переноса\* |
| `&` | `ANA` | логическое и |
| `#` | `XRA` | исключающее или |
| `!` | `ORA` | логическое или |
| `==` | `CMP` | сравнение |
| `=` | | присваивание |

\* только для операций над байтами.

Операции не имеют приоритетов и выполняются по порядку слева направо.
Круглые скобки используются только для выделения сложных операндов, они не нужны слева от знака присваивания `=` .
Операнды в выражении считаются двухбайтовыми, если в нём используются двухбайтовые регистры или выражение начинается с точки.
Операция сравнения имеет смысл только в конце выражения.

Пример: `X=Y+Z-10`  `HL=DE+BC`  `A=B-10H&X#Y!(88H)`  `.N=G#W==^(X+100)`

## Операции сдвига

| ATAS | ASM | Описание |
| --- | --- | --- |
| `<--` | `RLC` | сдвиг влево |
| `<<--` | `RAL` | сдвиг влево через перенос |
| `-->` | `RRC` | сдвиг вправо |
| `-->>` | `RAR` | сдвиг вправо через перенос |

Пример: `-->`  `<<--`

## Инкремент, декремент

Инкрементировать и декрементировать можно не только регистры, но и любые переменные.

Пример: `A+1`  `E-1`  `HL+1`  `X+1`  `.YW-1`  `.(N+80H)+1`

## Конструкция IF THEN

Эта конструкция здесь весьма ограничена, зато порождает оптимальные строки ассемблера.
Допустимы операции сравнения только `=`, `<>`, `<`, `>=` .
После `IF` может быть только одна операция сравнения и только два операнда справа и слева от неё.
После `THEN` допустимо только `RET`, `JMP`, `CALL` или имя подпрограммы.
`THEN` может быть опущено.

Пример:

```
IF A>=X THEN PPROG        IF HL=DE THEN RET        IF .X<Y JMP M1
IF .(456)>=(X+5) PPROG
```

Конструкция `IF THEN` введена для наглядности программ, без неё можно обойтись следующим образом:

```
A=A==^10   JNZ M1
```

что эквивалентно:

```
IF A<>^10 THEN JMP M1
```

## Стек

Загрузка регистра в стек: `[R` . Выгрузка: `R]` .
Где `R` соответствует регистрам `A`, `BC`, `DE`, `HL` .
Скобка без регистра означает загрузку или выгрузку всех регистров.

Пример: `[A`  `[BC`  `[`  `]`  `HL]`  `DE]` .

## Подпрограммы

Подпрограммы вызываются либо через `CALL`, либо просто именем без `CALL`.

Пример: `CALL PPR` либо `PPR` .

## Комментарии

Всё, что находится после знака `;` и до конца строки, считается комментарием.

## Прямая передача

Всё, что находится после отдельного знака `\` и до конца строки, передаётся в выходной файл без изменений с новой строки.

## Особенности трансляции и исключения

Над регистром `PC` возможна только одна операция: `PC=HL` .
Регистр `SP` может использоваться в выражениях только с операцией `+` или как первый операнд, или слева от знака `=` .

Пример: `SP=SP+SP`  `SP=HL`  `HL=SP`  `SP=8000H`  `SP=BC+DE` .

Аккумулятор используется во всех операциях, кроме сложения двухбайтовых чисел, поэтому имеет смысл использовать его только для хранения результата либо как первый операнд.
Регистр `HL` используется в байтовых операциях над переменными.

Пример:

```
A=A+X         ->  LXI  H,X
                  ADD  M
```

Регистр `HL` используется в двухбайтовых операциях для хранения промежуточных результатов, а `DE` в операциях над константами и переменными.
Поэтому выражение `X=Y+HL` эквивалентно `.X=Y+Y`, или `X=Y+Z+DE` эквивалентно `.X=Y+Z+Y` .

Результат трансляции некоторых выражений:

| ATAS | ASM |
| --- | --- |
| `-CY` | `CMC` |
| `CY=1` | `STC` |
| `HL.DE` | `XCHG` |
| `HL.(SP)` | `XTHL` |
| `A=(BC)` | `LDAX B` |
| `A=(DE)` | `LDAX D` |
| `A=(HL)` | `LDAX H` |
| `(BC)=A` | `STAX B` |
| `(DE)=A` | `STAX D` |
| `(HL)=A` | `STAX H` |
| `-A` | `CMA` |

Эти мнемоники в выходном тексте можно получить только из данных выражений.
