# Контроллер дисковода фирмы «COMAN»

Контроллер гибкого дисковода для ПЭВМ «Вектор-06Ц», выпускавшийся московской фирмой «COMAN». Собственных материалов в каталоге нет: ни принципиальной схемы, ни описания, ни снимка платы.

**Материалы в розыске.** Если у вас есть схема, фото платы или описание этого контроллера — каталог можно дополнить.

## Что в каталоге

| Файл                | Что это                                                                                                                                                                                                     |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `fdd_coman_mod.txt` | Текст о переделке контроллера под «МикроДОС» (CP866, CRLF). Относится не к исходной конструкции, а к варианту [coman_mod](../coman_mod); здесь лежит распакованная копия того же файла, что и в его архиве. |
