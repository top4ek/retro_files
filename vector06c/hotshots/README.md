Слайдшоу из кадров фильма «Горячие головы» и длинный скроллер.

Кроме всего прочего, обещается мегадемо «Assorty &ndash; Megademo» из Кирова, которая будет запускаться только через крутой и красивый загрузчик «Disk Loader» от Сергея Меринова/FMSSoft.

Также упоминается демо-слайдшоу «Robocop».

См. также [Assorty Megademo](../assorty).
