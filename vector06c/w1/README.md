Две игры в одной: первая игра называется «Спрут энд Колобок», вторая &ndash; кегельбан.

Спрут энд Колобок напоминает известную на PC игру «Перестройка», только вместо конъюнктурной на тот день темы, в «Спруте» используются милые сердцу образы Колобка и Ктулху.
