Реляционная система управления базами данных «РЕБУС», изначально разработанная для ПЭВМ «Роботрон PC-1715» (ОС SCP) и совместимых машин.
На дисках - версия для «Вектора-06Ц» (на титуле руководства: «в редакции для ПЭВМ Вектор-06Ц, 2026 г.»).

Требования: процессор 8080 или Z80, 48 КБ ОЗУ, ОС МикроДОС или РДС, дисковод или жёсткий диск.

Образы дисков:

- `REBUSDOS.FDD` - версия для МикроДОС 3.1.
- `REBUSRDS.FDD` - версия для РДС.

На дисках: `REBUS.COM` и оверлей `REBUSOVR.COM`, программа экранных форм `MAKET.COM` и оверлей `ZSCRN.OVL` («РЕБУС/ЭКРАН»), сортировка `REB-SORT.COM`, генераторы `DGEN`, `FORMGEN`, `LABELGEN`, `MENUGEN`.
Руководство программиста (редакция апреля 1987 года, 86 листов) лежит на диске в файле `REBUSDOC.TXT` (КОИ-8), сообщения системы - в `REBUSMSG.TXT`.
