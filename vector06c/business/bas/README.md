Популярная игра «Бизнес» (аналог игры «Монополия») для двух игроков.
Бейсик.

Для запуска в эмуляторе "Башкирия-2М":

1. Удерживая F3, нажать F11
2. Произойдет загрузка Бейсик 2.5
3. Нажать F12
4. Набрать команду CLOAD""
5. Выбрать в дилоговом окне файл business_part1.cas
6. После загрузки запустить выполнить команду RUN
7. Выбрать в дилоговом окне файл business_part2.cas
8. Игра загружена

См. также [Business ROM](../rom)
