Эта программа предназначена для работы с компьютером «Вектор-06Ц».

Измеряемый сигнал подается на разъем компьютера О-О (вход с магнитофона).

Диапазон измеряемых частот - 1 Гц...10 кГц.

Уровень сигнала должен составлять 0,1...1 В, время измерения сигнала - 1 с.
