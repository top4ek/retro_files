Публикация из «Радиолюбитель. Ваш компьютер.» - 1999 - №3. - С.33.

При ремонте системного блока компьютера «Вектор-06Ц», выпущенного в г.Кирове, довольно трудно понять, с какой конкретно микросхемой ОЗУ в данный момет работает процессор.
Для решения этого вопроса предлагаю таблицу соответствия между позиционным обозначением микросхем, разрядом слова данных и физическим адресом обращения микропроцессора к микросхемам ОЗУ.

Адреса ОЗУ указаны в десятичной системе счисления.

Надеюсь, что приведенные сведения пригодятся радиолюбителям, занимающимся ремонтом компьютеров.

| Разряд слова данных | Позиционное обозначение микросхемы ОЗУ | | | |
| --- | --- | --- | --- | --- |
| D1 | Д49 | Д57 | Д65 | Д73 |
| D0 | Д50 | Д58 | Д66 | Д74 |
| D3 | Д51 | Д59 | Д67 | Д75 |
| D2 | Д52 | Д60 | Д68 | Д76 |
| D5 | Д53 | Д61 | Д69 | Д77 |
| D4 | Д54 | Д62 | Д70 | Д78 |
| D7 | Д55 | Д63 | Д71 | Д79 |
| D6 | Д56 | Д64 | Д72 | Д80 |
| Адрес ОЗУ (страница 1) | 0...8191 | 8192...16383 | 16384...24575 | 24576...32767 |
| Адрес ОЗУ (страница 2) | 32768...40959 | 40960...49151 | 49152...59343 | 57344...65535 |

Примечания к расшифровке:

- Шапка «Позиционное обозначение микросхемы ОЗУ» в оригинале объединяет четыре правых столбца.
- В таблице разряды перечислены в том порядке, как в оригинале (D1, D0, D3, D2, D5, D4, D7, D6).
- В последней строке в оригинале напечатано «49152...59343». Судя по соседним диапазонам (предыдущий заканчивается на 49151, следующий начинается с 57344), это опечатка: должно быть 57343.
- В оригинале: «в данный момет» (пропущена буква «н»).

В верхней части страницы 33 опубликовано окончание листинга программы предыдущей статьи и подпись «Г.ИГНАТЬЕВ, Минская обл., Копыльский р-н, д.Тимковичи», относящаяся к ней; к данному материалу это не относится и здесь не расшифровывается.
Подписи под самой заметкой на с.33 нет - авторство указано по оглавлению сборника.
