# Scuba Dive

Scuba Dive — игра Durell Software, выпущенная для ZX Spectrum в 1983 году.
Здесь собраны её порты для «Вектора-06Ц» с разными процессорами.

## [Scuba Dive Z80](z80)

Порт Никиты Зимина для «Вектора-06Ц» с процессором Z80.
В каталоге находятся ROM-образ игры, варианты с читами и архив исходных файлов со скриптами сборки.

## [Scuba Dive DX](dx)

Версия для стандартного процессора КР580ВМ80А, основанная на Z80-порте.
Доступны русская и английская версии игры, каждая — с заставкой и без неё.
