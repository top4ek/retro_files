Вертолетик, постепенно снижаясь, летает над полным небоскребов мегаполисом.
Небоскребы, очевидно, мешают мирному полету винтокрылой машинки и угрожают столкновением.
Эта проблема решается изящным способом — здания вместе со всех их содержимым понемногу подвергаются сносу при помощи неограниченного запаса бомб.
