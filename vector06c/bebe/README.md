Вредоносная утилита «Вирус БЕ-БЕ», которая после запуска уничтожает все файлы на диске.
В файле содержатся ругательства в адрес некоторых персонажей, неприличные призывы и оскорбление сэра SINCLAIR-а (или его знаменитого детища).

Инструкция по применению:

Переименовать файл «bebe.vir» в «bebe.com», разместить на образе диска с единственными копиями самых важных программ и запустить.
