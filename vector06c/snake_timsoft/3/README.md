Гуманная игра. Травоядный питон поедает цветы, избегая встреч с канцелярскими кнопками и преградами. Это третья версия первой авторской игры в кодах, написанной на LS-Pascal. По сравнению со второй версией игры, в этой была упрощена заставка, изменен цвет питона и переписан движок питона. Распространялась пиратским образом.

См. также [Snake 1](../1), [Snake 2](../2).
