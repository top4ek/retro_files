Начальный загрузчик ПЭВМ «Вектор-06Ц» на 512 байт.

Считан при помощи [ROM-DUMPER (копировщик загрузчика)](../romdump) без извлечения ПЗУ.

Отличается от кишиневского 512-байтного варианта [Загрузчик «Вектор-06Ц» (базовый, 512 байт, Кишинев)](../kish1)

измененной подпрограммой определения среднего времени между фронтами сигналов поступающих с МЛ.

В исходном файле загрузчика первый байт равен 0x00, что некорректно.

Вероятно "потекла" ПЗУ или технологический брак.

По логике работы загрузчика вместо 0x00 должно быть 0x3E.

"boot_minsk_mod.bin"  - исправленный файл.

Производство: МПОВТ, г.Минск, Белорусь, 1990г.
