Разыскивается Микро-ДОС (BIOS FP14.3), предназначенная для работы с модифицированным квазидиском, описанным в журнале «Радиолюбитель» №11/1995. Не путать с [Микро-ДОС (BIOS F14)](../f14) того же автора, которая работает с обычным квазидиском.
