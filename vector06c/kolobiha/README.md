Шарик прыгает через лабиринт и преодолевает препятствия.
Похожа на современную игру Within a Deep Forest.
Сложный распаковщик, использующий каждый закоулок процессора и компьютера, может использоваться как тест на качество эмулятора.
Также есть информация, что оригинальный вариант данной игры не работает с процессором КР580ВМ1.

Есть вариант игры с интро и трейнером от S.E.S. Он работает на КР580ВМ1, а в intro на этом процессоре запускается дополнительная часть CPU Evolution (информация из [Scaner №5](../scaner/5)).
Интро интересно само по себе.
