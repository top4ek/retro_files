Эмулятор ПЭВМ «Вектор-06Ц» для Windows, автор — Игорь Титарь.

Процессор КР580ВМ1 поддерживается начиная с версии 5.58.
С версии 5.64 есть менеджер памяти (File → Memory Manager), которым файл загружается в ОЗУ с нужного адреса.
Через [Загрузчик MBR](../mbr) эмулятор запускает файлы в формате «Криста-2», сохранённые в WAV.

Свежие версии и архив выпусков — на [Emu-France](https://www.emu-france.com/emulateurs/10-ordinateurs/402-vector-06c/3626-virtual-vector).
Эмулятор также лежит в подборке эмуляторов «Вектора» на [TIMSoft](https://vector06c.zx-pk.ru/emul.html).
