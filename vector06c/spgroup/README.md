Игры для запуска требуют код. Код неизвестен. Описания игры нет.

ВНИМАНИЕ!

Запустить игру можно одновременным нажатием четырех клавиш курсора, если они настроены на цифровой клавиатуре в эмуляторе [http://bashkiria-2m.narod.ru/](http://bashkiria-2m.narod.ru/)

Для этого в файле layout.kbd (см. папку Vector06c) вместо

x-left x-up x-right x-down

должно быть написано

left up right down
