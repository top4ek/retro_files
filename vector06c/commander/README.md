Мельтешащий клон Space Invaders, который никак не смог бы вызвать дефицит четвертаков в Японии.

В заставке commandz фальшиво играет музыка Владимира Дашкевича из «Шерлока Холмса». Другая версия содержит заставку центра «Байт» без музыки.
