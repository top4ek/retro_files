Тарзан собирает бананы для Джейн.
Джейн девушка себе на уме и бананов нужно много.

По сути это версия [Lode Runner](../loderun) с цветной графикой.
Вопрос авторства окончательно запутан.
В этот раз автором, тайным образом, указан Цепелев И. из Серова.
