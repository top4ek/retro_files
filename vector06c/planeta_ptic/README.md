«Прекрасная зеленая планета, населенная разумными птицами, захвачена пиратами для испытания своих летающих кораблей.
Испытания превратили планету в пустыню.
Тебе, Капитан, надо уничтожить корабли пиратов — этим ты вернешь планете её зеленую природу.
За каждый сбитый корабль — плюс 1 очко».
