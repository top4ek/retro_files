Игра «King’s Bounty», работает только под ОС РДС.

В архиве загрузочный образ квазидиска EDD и образ FDD.
Для запуска игры в эмуляторе [http://bashkiria-2m.narod.ru/](http://bashkiria-2m.narod.ru/) подключить образы EDD и FDD, затем, удерживая F1+F2, однократно нажать F11.
После загрузки программы нажать F12.
После запуска РДС набрать «KB» и нажать ВК.
