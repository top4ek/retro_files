Проигрыватель музыкальных файлов редактора «Звуковой агрессор» (формат SAM).
При автономном запуске работает, как дема со скроллом.
При запуске с диска производит поиск файлов SAM и проигрывает их.
В архиве с исходником представлена процедура для проигрывания файлов формата SAM.
