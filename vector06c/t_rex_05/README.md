Dizzy-подобная игра. Очень хорошая графика.

После загрузки основной части на титульном скрине набрать «cheat-mode-activated!», тогда в игре можно нажимать цифровые клавиши от 1—3 для просмотра всех концовок.

Диск загрузочный. Для загрузки с диска в эмуляторе [http://bashkiria-2m.narod.ru/](http://bashkiria-2m.narod.ru/) удерживая F1+F2, однократно нажать F11. После загрузки программы нажать F12.
