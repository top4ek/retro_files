Призраки продят по игровому полю.
Единственный способ избавится от них (и перейти на следующий уровень) - придавить их камнями.
Будьте внимательны, камней не намного больше, чем привидений.
Толкать их можно при помощи клавиш `РУС/LAT` и стрелок.
