«ROM-REAPER»

См. также [ROM-DUMPER (копировщик загрузчика)](../romdump)

Далее по тексту используются термины:

ПК - персональный компьютер (IBM-совместимый)

ПЭВМ - «Вектор-06Ц»

Программа ROM-REAPER предназначена для копирования содержимого ПЗУ начального загрузчика без извлечения микросхемы ПЗУ.

Программа может быть использована на ПЭВМ «Вектор-06Ц».

При копировании используется особенность начального загрузчика, благодаря которой есть возможность перехвата управления пользовательской программой (автозапуск).

Не все загрузчики могут быть скопированы таким образом, например, исключением является [Загрузчик «Вектор-06Ц» (2048 байт, Киров)](../loadbyte).

В методике использованы:

а) идея автозапуска, описана в [Байт](../byte) №2 1991г.

б) копировщик [TURBO-COPY](../turbo)

в) процедура записи файла в формате ROM из [Байт](../byte) №8

г) [ROM-DUMPER (копировщик загрузчика)](../romdump)

Методика копирования:

1. Подключить магнитофонный вход ПЭВМ к линейному выходу звуковой карты ПК

2. Подключить магнитофонный выход ПЭВМ к линейному входу звуковой карты ПК

3. Включить ПЭВМ и загрузить программу romreaper.wav

4. ВНИМАНИЕ! ПОСЛЕ ЗАГРУЗКИ НЕ НАЖИМАТЬ `БЛК`+`СБР` !!!

5. На ПК включить запись с линейного входа

6. Нажать на ПЭВМ клавишу `РУС`

7. Начнется выгрузка содержимого ПЗУ в формате ROM

8. По окончании записи сохранить полученный файл в формате WAV и выслать по указанным ниже адресам
