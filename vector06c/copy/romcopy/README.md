Программа «ROM Copy» предназначена для копирования и обработки файлов в форматах ROM и TURBO+.

В архиве несколько программ: собственно ROM Copy, ROM Copy Info с подробной инструкцией по использованию ROM Copy, а также ROM Copy Demo.
