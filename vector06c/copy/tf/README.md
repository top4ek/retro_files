Копирует файлы в форматах ROM,MON,BAS

Защиту игнорирует, не снимает;

выводит количество блоков;

выводит имя файла, редактирует.

РУС/LAT + БЛК + СБР - вывод справки

УС + БЛК + СБР - переключение форматов ROM или MON/BAS
