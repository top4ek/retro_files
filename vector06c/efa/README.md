Вы — одна из самых быстрых и ядовитых змей, эфа, и вы чертовски голодны.
Розовые ромбики изображают заек, птичек и прочую еду.

Характерный для эфы песчаной &#132;боковой ход&#147; в этой игре не реализован, из чего можно сделать вывод, что это симулятор эфы пёстрой, которая предпочитает передвигаться классическим змеиным ходом.
