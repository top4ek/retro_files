Если во время сброса удерживать клавишу CC, запустится начальный загрузчик (а-ля Вектор).

Загрузка программ для ПК Вектор Старт-1200 в [Эмулятор «Башкирия-2М»](../bashkiria_2m) (конфигурация Vector-1200):

Загрузка файлов с расширением rk (формат Монитор-1200)

В мониторе I, Enter - в диалоге открытия файла выбираем нужный, после загрузки T, Enter.

Загрузка файлов с расширением rkb (формат Basic-1200)

В бейсике MLOAD, Enter - в диалоге открытия файла выбираем нужный, после загрузки RUN, Enter.

Для успешного запуска игры "Удавчик" перед запуском бейсика в мониторе надо подать команду #5000. Еще один положительный эффект от этой команды - бейсик стартует сразу, без рисования заставки.
